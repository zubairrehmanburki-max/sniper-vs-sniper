# Art credits

- `blouberg_sunrise_2_1k.hdr`, `quarry_01_1k.hdr`, `venice_sunset_1k.hdr`: HDRI skies by Poly Haven (CC0), as shipped with the three.js examples. The game hazes out the lower part of each at load time.
- `Soldier.glb`: rigged soldier from the three.js examples (Mixamo "Vanguard" character), re-tinted olive and posed per stance in `gfx/figure.ts`.
- `grass.jpg`, `grass_n.jpg`: `grasslight-big` terrain textures from the three.js examples, downscaled to 1024 px.
- `waternormals.jpg`: water normal map from the three.js examples.
- `smoke.png`: smoke sprite from the three.js examples (OpenGameArt, CC0).
- `concrete*.jpg`, `asphalt*.jpg`, `rust.jpg`, `trees.png`: generated for this game (noise-based textures and painted tree billboards); no external source.
